# 翻譯詞彙表（英文版）

Claude 翻譯網站內容時照這份用詞，全站才會一致。同仁校對時若改了某個固定譯名，請也改這裡（或告訴 Claude）。

## 規則

- **人名不翻譯、不音譯**（含「小明老師」這類稱呼）：保留中文。本人提供英文名後，填在後台該位理監事／作者的「英文姓名」欄位。
- **地名**用通行的官方拼音：苗栗 Miaoli、三義 Sanyi、台東 Taitung、苗栗農工 Miaoli Agricultural and Industrial Vocational High School。
- **書名、片名**沒有官方英文名時保留中文，前面說明是什麼：the book 《漢字好好教 好好教漢字》、the documentary 《種土》。
- **日期文字**（活動的「日期顯示文字」）保留原本的數字格式，例如 `2026 · 06 · 28`；網站靠這個格式判斷活動是否已結束。「每月第二個週六」這類文字照意思翻。
- 網址、圖片、圖示、`_key` 一律照抄（腳本會檢查）。
- 「○○」照抄。
