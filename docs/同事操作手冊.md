# 官網操作手冊（給學會同仁）

不用會寫程式。打開 Claude，**用平常說話的方式**告訴它要做什麼就好。
下面是常用的說法，直接複製貼上也可以。

---

## 一、最常用的幾句話

| 你想做的事 | 對 Claude 說 | 會發生什麼 |
|---|---|---|
| 在自己電腦上看網站 | **「幫我開網站」** | Claude 啟動預覽，給你一個網址（http://localhost:4321），用瀏覽器打開就能看。這只有你看得到，不會影響正式網站。 |
| 關掉預覽 | **「關掉網站預覽」** | 預覽停止。 |
| 修改網站 | **「把首頁的○○改成△△」** | Claude 修改，改完你重新整理預覽頁面確認。 |
| 改好了要上線 | **「推上去」**（或「上架」「部署」「更新網站」） | Claude 把修改送出，**約 1～2 分鐘後**正式網站更新。 |
| 看看改了什麼 | **「我改了哪些東西還沒上線？」** | Claude 用白話列出還沒推上去的修改。 |
| 改錯了想放棄 | **「剛剛的修改不要了，恢復原狀」** | 還沒推上去的修改會被還原。 |
| 問後台網址 | **「後台網址是什麼？」** | 見下方第三節。 |
| 新內容要有英文版 | **「幫我把○○翻成英文」**（例：「幫我把新的專欄文章翻成英文」） | Claude 翻好讓你在預覽裡看英文版；你說「推上去」才會寫進後台並上線。 |
| 查還有哪些沒翻 | **「還有哪些內容沒有英文版？」** | Claude 列出尚未翻譯、中文改過後英文可能過時、還沒校對的內容。 |

> ⚠️ **只有你說「推上去」，Claude 才會讓修改上線。** 在那之前你怎麼改、怎麼試都不會影響正式網站，請放心。

## 二、兩種修改方式，別搞混

| | **後台（Sanity）** | **請 Claude 改** |
|---|---|---|
| 適合 | 所有文字、照片、文章、活動、理監事名單、選單、頁尾、聯絡資訊 | 版面、樣式、新增頁面、功能 |
| 在哪裡改 | https://tslea.sanity.studio/ | 對 Claude 說 |
| 怎麼上線 | 在後台按 **「發布」**，約 1～2 分鐘自動更新 | 對 Claude 說 **「推上去」** |

**日常的文字、照片和文章更新，用後台就好，不需要 Claude。**

### 網站上的東西，要到後台哪裡改

| 想改的地方 | 後台位置 |

| 五大學會活動（身呼吸、慢活日…）的圖、說明；也是活動的分類標籤 | 📝 內容 → 學會活動類別 |
| 首頁「探索更多」四個方塊、「一起慢下來」 | 📄 頁面文案 → 首頁 →「探索更多」「行動呼籲」分頁 |
| 學會簡介（首頁也會顯示前兩段） | 📄 頁面文案 → 認識學會 |

| 頁首選單、右上角按鈕、頁尾連結 | 🧭 選單與頁尾 |
| Email、地址、Facebook 網址、統一編號、分享圖 | ⚙️ 網站設定 |

### 英文版

網站每一頁都有英文版，網址前面多 `/en`（例：https://slowlivingeducation.org/en/about），右上角的地球圖示可以切換語言。

- **英文內容也在後台**：打開任何一份文件，上方多了一個 **「English 英文版」** 分頁，裡面是英文欄位，和中文分頁一一對應。直接改英文、按「發布」即可上線。
- **英文由 Claude 翻譯**：新增或修改中文之後，請跟 Claude 說「幫我把○○翻成英文」。還沒翻的內容，英文網站會先顯示中文，並註明「English translation in progress」。
- **「已校對」**：英文分頁最下方有「已校對」勾選。看過、改好英文後請勾起來；Claude 之後不會覆蓋已校對的內容。
- **分頁上方的提醒**：「尚未翻譯」＝英文網站目前顯示中文；「中文在翻譯後改過，英文可能已過時」＝請找 Claude 重新翻譯；「尚未校對」＝英文還沒人看過。
- **人名**：英文網站預設顯示中文姓名。理監事或作者本人提供英文名後，填在「English 英文版」分頁的「英文姓名」。不要自己幫人取英文名。
- 英文的固定譯名（學會名稱、主題、活動名稱、職稱）在 `docs/翻譯詞彙表.md`。

小提醒：
- 上傳有人物的照片前，先確認當事人同意公開，**學生與未成年人尤其要取得同意**。每張照片請填「照片說明」。
- **影片**：先上傳到學會的 YouTube 頻道（可設「不公開」），再把網址貼到活動的「活動影片」，或在內文插入「影片」。後台不放影片檔。
- 「加入我們」「與我們合作」的按鈕：有線上表單時，把表單網址貼到「按鈕連結」；沒有的話留空，按鈕會自動變成寄信給學會。
- 選單連結填站內路徑，例如 `/about`；改選單時，連到 `/partner#school` 這類「#」後面的名稱不要改。

## 四、標準流程（請 Claude 改網站時）

1. 說 **「幫我開網站」** → 打開預覽網址
2. 描述要改什麼，例如：「與我們合作頁的『個人捐款』標題改成『支持我們』」
3. 重新整理預覽頁面，確認改對了（不對就繼續跟 Claude 說）
4. 確認沒問題 → 說 **「推上去」**
5. 等 1～2 分鐘，到正式網站確認

---

## 五、絕對不要做的事

- **不要把會員名冊、會議紀錄、身分證字號、活動原始照片交給 Claude 放進網站。**
  送進網站的東西會**永久公開**，事後刪不掉。這些資料請放學會的 Google 共用雲端硬碟。
- 不要在後台上傳含個人資料的圖片（例如報名表截圖）。
- 不確定能不能公開的內容，先問資訊總監。

---

## 六、遇到問題

- Claude 回了一堆看不懂的英文或錯誤訊息 → 直接說 **「用白話告訴我發生什麼事、我該怎麼做」**
- 預覽網址打不開 → 說 **「網站預覽打不開，幫我看看」**
- 推上去之後正式網站沒變 → 等 2 分鐘、按 Ctrl+F5 重新整理；還是沒變就說 **「我推上去了但網站沒更新」**
- 其他問題 → 聯絡資訊總監
